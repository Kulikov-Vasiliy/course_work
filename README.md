# course_work
course work python
## О проекте
Первая курсовая работа, основная цель-закрепление полученных навыков и знаний по работе с библиотеками json, read_excel, pandas, requests, datetime, logging
В проекте был применен код, суть которого подражает библиотекам collections и re
## По установке:
  * Для PyCharm:
    1. клонировать репозиторий, введя в терминале git clone https://github.com/Kulikov-Vasiliy/homework-python
    2. установить зависимости через активированное виртуальное окружение: pip install -r requirements.txt(пока не добавлено в проект)
  * Для GitHub:
    1. на странице проекта на кнопке <> Code открыть выпадающий список
    2. выбрать download zip или клонировать через ссылку https или ssh
По применению проекта:
1. открыть модуль main через pycharm
2. сделать пробег у current file/комбинацией shift + f10/командой python src\main в терминале
## Дополнительно
- все рабочие и пусковой модули находятся в src
- информация с которой работают модули расположена в data
- utils содержит вспомогательные функции для views
- reports создает файл transactions.xlsx в data, в то время как остальные формируют json-ответ
- main, будучи пусковым модулем выводит json-ответ, запускает процесс обработки и создания файла как результат работы reports
